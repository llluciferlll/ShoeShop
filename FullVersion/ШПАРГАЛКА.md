# ООО «Обувь» — приложение WinForms (модули 2–4 ДЭ 09.02.07-2-2026)

## 1. Подготовка проекта (5 минут)

1. Visual Studio → «Приложение Windows Forms», .NET 8, имя `ShoeShop`.
2. Проект → «Управление пакетами NuGet» → установить **Npgsql**.
3. Скопировать в папку проекта `1.jpg … 10.jpg`, `picture.png`, `Icon.png`, `Icon.ico`.
   Выделить их в обозревателе решений → Свойства → «Копировать в выходной каталог» = **Копировать более новый**.
4. В `Db.cs` поправить строку подключения (имя БД, пароль postgres).

| Таблица | Столбцы |

## 5. Восемь приёмов, на которых держится весь код

1. **Один метод для всех запросов**: `Db.Query("... $1 ... $2", значение1, значение2)` возвращает DataTable. Им же делаются insert, update и delete.
2. **Ошибки ловятся в одном месте**: `Application.ThreadException` в `Program.cs`, поэтому try/catch в формах не нужен и приложение не падает.
3. **Навигация через ShowDialog**: `Hide(); new Форма().ShowDialog(); Show();`. Кнопки «Выход» и «Назад» — это просто `Close()`. Модальное окно заодно не даёт открыть второе окно редактирования.
4. **Роль хранится в `Program.Role`**, а лишние кнопки скрываются через `Visible = false`.
5. **Поиск, фильтр и сортировка — один SQL-запрос**: `ilike` по склеенным полям, `($2 = 'Все поставщики' or s.name = $2)` и `order by quantity * 1` либо `* -1`.
6. **Карточка (UserControl) получает DataRow** и сама себя заполняет. Клик по любой её надписи передаётся на всю карточку.
7. **Одна форма для добавления и редактирования**: если `row == null`, это новая запись, и её ID = `max(id) + 1`. Insert и update берут один и тот же массив `values`.
8. **Картинки грузятся через `Db.LoadImage`**: файл не блокируется (старое фото можно удалить), а при отсутствии файла подставляется `picture.png`.
