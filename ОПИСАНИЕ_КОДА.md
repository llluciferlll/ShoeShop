## 1. Что вообще делает приложение

```
 ┌──────────────────────┐        логин и пароль верные         ┌───────────────────────────┐
 │   Окно входа (Login) │ ───────────────────────────────────▶ │ Главное окно (Form1)      │
 │                      │                                      │ - выбор таблицы           │
 │  Логин:  [________]  │        «Войти как гость»             │ - таблица с данными       │
 │  Пароль: [________]  │ ───────────────────────────────────▶ │ - «Сохранить» (для админа)│
 │  [Войти] [Гость]     │                                      │ - «Выход»                 │
 └──────────────────────┘ ◀─────────── кнопка «Выход» ──────── └───────────────────────────┘
```

1. Запускается **окно входа**.
2. Пользователь вводит логин и пароль → программа ищет его в таблице `users`.
3. Если нашёлся — открывается **главное окно**, и в нём видна **роль** пользователя.
4. В главном окне в выпадающем списке выбирается таблица → она показывается в сетке.
5. **Администратор** может менять данные прямо в сетке и нажать «Сохранить».
   Все остальные (менеджер, клиент, гость) могут только смотреть.
6. Кнопка «Выход» возвращает на окно входа.

## 3. База данных, которую ждёт код

Код обращается к базе **по именам**. Если имя в базе отличается хоть на одну букву — будет ошибка.

### Таблица `users` (пользователи) — используется для входа

| Столбец | Что хранит | Пример | Используется в коде? |
|---|---|---|---|
| `id` | номер пользователя (первичный ключ) | 1 | нет (но нужен для сохранения) |
| `role` | роль **текстом** | `Администратор` | **да**, в `Login.cs` |
| `full_name` | ФИО | Никифорова Весения Николаевна | нет |
| `login` | логин | 94d5ous@gmail.com | **да**, в `Login.cs` |
| `password` | пароль | uzWC67 | **да**, в `Login.cs` |

### Таблица `products` (товары) — показывается в главном окне

Код делает `select * from products`, то есть показывает **все столбцы, какие есть**.
Названия столбцов внутри таблицы для кода **не важны** — важно только имя самой таблицы.

### Остальные таблицы (`orders`, `pickup_points`)

Есть в базе, но в простой версии в списке их нет. Как добавить — см. [раздел 8.3](#83-хочу-показывать-ещё-одну-таблицу-например-заказы).

### Где это всё задаётся

Вся структура описана в файле `shoes_db.sql`. Если открыть его в pgAdmin (Query Tool) и
нажать F5 — таблицы создадутся заново с данными из Excel.

## 4. Program.cs — точка запуска

```csharp
namespace ShoeShop
{
    internal static class Program
    {
        [STAThread]
        static void Main()
        {
            ApplicationConfiguration.Initialize();
            Application.Run(new Login());
        }
    }
}
```

| Строка | Что значит простыми словами |
|---|---|
| `namespace ShoeShop` | «Фамилия» всех классов проекта. Должна совпадать во всех файлах. |
| `static void Main()` | Самое начало программы. Отсюда Windows запускает приложение. |
| `[STAThread]` | Служебная пометка, без неё окна Windows Forms работают неправильно. Не трогать. |
| `ApplicationConfiguration.Initialize();` | Включает стандартные настройки (стили кнопок, чёткость на мониторе). Не трогать. |
| `Application.Run(new Login());` | **Открыть окно входа первым.** Когда это окно закроется — программа завершится. |

**Что здесь менять:** ничего. Единственное — если окно входа называется не `Login`,
а, например, `Form2`, то пишем `Application.Run(new Form2());`.

### 5.2. Код построчно

```csharp
using Npgsql;
```
Подключаем библиотеку **Npgsql** — она умеет разговаривать с PostgreSQL.
Без этой строки слова `NpgsqlConnection`, `NpgsqlCommand` будут подчёркнуты красным.
Сам пакет ставится через NuGet (ПКМ по проекту → «Управление пакетами NuGet» → Npgsql).

```csharp
string connStr = "Server=localhost;Port=5432;Database=shoes;User Id=postgres;Password=32351616aa";
```
**Строка подключения** — адрес базы данных. Разберём по кусочкам:

| Кусочек | Значение | Когда менять |
|---|---|---|
| `Server=localhost` | база на этом же компьютере | почти никогда |
| `Port=5432` | стандартный порт PostgreSQL | если при установке PostgreSQL указали другой |
| `Database=shoes` | **имя базы в pgAdmin** | **ВСЕГДА проверить!** Имя должно совпадать с тем, что слева в pgAdmin под «Databases» |
| `User Id=postgres` | пользователь PostgreSQL | обычно не меняется |
| `Password=...` | **пароль от PostgreSQL** (который вводили при установке / при входе в pgAdmin) | **ВСЕГДА проверить!** |

> ⚠️ Строка подключения есть **в двух файлах**: `Login.cs` и `Form1.cs`. Менять нужно **в обоих**.

```csharp
public Login()
{
    InitializeComponent();
}
```
**Конструктор** — выполняется, когда окно создаётся.
`InitializeComponent()` — создаёт все кнопки и поля из дизайнера. **Без неё окно будет пустым и программа упадёт.**

```csharp
private void button1_Click(object sender, EventArgs e)
{
```
Этот кусок выполняется при **нажатии на «Войти»** (`button1`).
Создаётся сам: в дизайнере **двойной щелчок по кнопке**.

```csharp
    using var conn = new NpgsqlConnection(connStr);
    conn.Open();
```
Создаём подключение к базе по адресу `connStr` и открываем его.
`using` значит: «когда метод закончится — подключение закрой сам».

```csharp
    var cmd = new NpgsqlCommand("SELECT role FROM users WHERE login = @l AND password = @p", conn);
```
Готовим SQL-запрос: **«дай роль пользователя, у которого такой логин и такой пароль»**.

- `role` — **столбец**, который хотим получить;
- `users` — **таблица**, где ищем;
- `login`, `password` — **столбцы**, по которым ищем;
- `@l` и `@p` — **параметры**, «дырки», куда подставится то, что ввёл пользователь.

> 🔧 **Это главное место, которое меняется под другую базу.** См. [раздел 8.1](#81-у-меня-таблица-пользователей-называется-по-другому).

```csharp
    cmd.Parameters.AddWithValue("@l", textBox1.Text);
    cmd.Parameters.AddWithValue("@p", textBox2.Text);
```
Подставляем в «дырки» текст из полей: в `@l` — логин из `textBox1`, в `@p` — пароль из `textBox2`.
Почему не склеиваем строку руками: так безопаснее (защита от SQL-инъекций) и не ломается на кавычках.

```csharp
    var role = cmd.ExecuteScalar();
```
Выполняем запрос. `ExecuteScalar` возвращает **одно значение** — первую ячейку результата, то есть роль.
Если такого пользователя нет — вернётся `null` (пусто).

```csharp
    if (role == null)
    {
        MessageBox.Show("Неверный логин или пароль!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
        return;
    }
```
Если пусто — показываем окно с ошибкой (красный крестик `MessageBoxIcon.Error`) и **выходим** (`return`),
дальше код не выполняется.

`MessageBox.Show(текст, заголовок, кнопки, значок)` — стандартное окно сообщения.

```csharp
    OpenMain(role.ToString());
}
```
Если пользователь нашёлся — открываем главное окно и передаём туда роль (`.ToString()` превращает её в текст).

```csharp
private void button2_Click(object sender, EventArgs e)
{
    OpenMain("Гость");
}
```
Кнопка **«Войти как гость»**: базу не спрашиваем, сразу открываем главное окно с ролью «Гость».

```csharp
void OpenMain(string role)
{
    Hide();
    new Form1(role).ShowDialog();
    textBox2.Clear();
    Show();
}
```
Общий метод «открыть главное окно». Порядок:

1. `Hide();` — **прячем** окно входа (не закрываем! иначе программа завершится);
2. `new Form1(role).ShowDialog();` — **создаём и показываем** главное окно, передаём роль.
   `ShowDialog` — программа **ждёт на этой строке**, пока главное окно не закроют;
3. `textBox2.Clear();` — когда вернулись, стираем пароль;
4. `Show();` — снова **показываем** окно входа.

Так работает кнопка «Выход»: главное окно закрывается → код идёт дальше → окно входа появляется снова.

### 6.2. Код построчно

```csharp
using System.Data;
using Npgsql;
```
`System.Data` — нужна для `DataTable` (таблица в памяти). `Npgsql` — для работы с PostgreSQL.

```csharp
DataTable dt;
```
**Таблица в памяти программы.** Сюда загружаются строки из базы, сетка (`dataGridView1`) показывает именно её.
Объявлена здесь (вне методов), чтобы ею могли пользоваться и загрузка, и сохранение.

```csharp
string connStr = "Server=localhost;Port=5432;Database=shoes;User Id=postgres;Password=...";
```
Та же строка подключения, что в `Login.cs`. **Менять вместе с ней.**

```csharp
public Form1(string role)
{
    InitializeComponent();
    label1.Text = role;
```
Конструктор главного окна. В скобках `string role` — сюда приходит роль из окна входа.
`label1.Text = role;` — пишем роль в правый верхний угол.

```csharp
    if (role == "Администратор")
    {
        dataGridView1.ReadOnly = false;
        dataGridView1.AllowUserToAddRows = true;
        dataGridView1.AllowUserToDeleteRows = true;
        comboBox1.Items.Add("users");
    }
```
**Только для администратора:**
- `ReadOnly = false` — можно редактировать ячейки;
- `AllowUserToAddRows = true` — внизу появляется пустая строка для добавления;
- `AllowUserToDeleteRows = true` — можно удалить строку (выделить строку щелчком слева и нажать Delete);
- `comboBox1.Items.Add("users")` — в список добавляется таблица пользователей (остальные её не видят — там пароли).

> 🔧 Слово `"Администратор"` должно **буква в букву** совпадать с тем, что лежит в столбце `role` в базе.
> Если в базе написано `admin` или `Админ` — меняем здесь.

```csharp
    comboBox1.Items.Add("products");
}
```
Таблицу товаров добавляем **всем** ролям.

> 🔧 `"products"` — это **имя таблицы в базе**. Если таблица называется `tovar` — пишем `"tovar"`.

```csharp
private void comboBox1_SelectedIndexChanged(object sender, EventArgs e)
{
    dt = new DataTable();
    new NpgsqlDataAdapter("select * from " + comboBox1.Text, connStr).Fill(dt);
    dataGridView1.DataSource = dt;
}
```
Срабатывает, когда **в списке выбрали таблицу**:

1. `dt = new DataTable();` — создаём пустую таблицу в памяти;
2. `"select * from " + comboBox1.Text` — склеиваем запрос, например `select * from products`
   (`comboBox1.Text` — то, что выбрано в списке);
3. `NpgsqlDataAdapter(запрос, connStr)` — «переносчик» данных между базой и программой;
4. `.Fill(dt)` — выполнить запрос и **залить результат** в `dt` (подключение откроется и закроется само);
5. `dataGridView1.DataSource = dt;` — сказать сетке: «показывай вот эту таблицу».

```csharp
private void button2_Click(object sender, EventArgs e)
{
    var da = new NpgsqlDataAdapter("select * from " + comboBox1.Text, connStr);
    new NpgsqlCommandBuilder(da);
    da.Update(dt);
    MessageBox.Show("Изменения сохранены", "Информация", MessageBoxButtons.OK, MessageBoxIcon.Information);
}
```
Кнопка **«Сохранить»** — записывает изменения из сетки обратно в базу:

1. Создаём такой же «переносчик» для выбранной таблицы;
2. `new NpgsqlCommandBuilder(da);` — **магия**: этот объект сам пишет SQL-команды
   `INSERT` (для новых строк), `UPDATE` (для изменённых), `DELETE` (для удалённых);
3. `da.Update(dt);` — пройтись по `dt` и отправить в базу все изменения;
4. Показываем сообщение «Изменения сохранены» (синий значок `Information`).

> ⚠️ `NpgsqlCommandBuilder` работает **только если у таблицы есть первичный ключ** (PRIMARY KEY).
> Если ключа нет — будет ошибка при сохранении. В `shoes_db.sql` ключ `id` есть у всех таблиц.

```csharp
private void button1_Click(object sender, EventArgs e)
{
    Close();
}
```
Кнопка **«Выход»**: закрыть главное окно. После этого в `Login.cs` выполнится `Show()` — вернётся окно входа.

## 7. Файлы *.Designer.cs — внешний вид окон

Эти файлы **пишет Visual Studio сама**, когда вы двигаете кнопки мышкой. Руками их **не правим**.

Что там есть (на примере кнопки):
```csharp
button1.Location = new Point(110, 115);   // где стоит (x, y)
button1.Size = new Size(240, 35);         // размер (ширина, высота)
button1.Text = "Войти";                   // надпись
button1.Click += button1_Click;           // какой метод вызвать при нажатии
```

Последняя строка (`Click += ...`) — это и есть **связь кнопки с кодом**. Она появляется сама,
когда в дизайнере делаешь двойной щелчок по кнопке.

> ❗ Если **переименовали метод** в `.cs` руками — в `.Designer.cs` останется старое имя, будет ошибка
> «не содержит определения для button1_Click». Решение: переименовывать через ПКМ → «Переименовать» (F2)
> — тогда Visual Studio поменяет имя везде.

|---|---|---|---|

| Пароль PostgreSQL | `Password=...` | Login.cs **и** Form1.cs | 7 / 9 |
| Таблица пользователей | `FROM users` | Login.cs | 18 |
| Столбец с ролью | `SELECT role` | Login.cs | 18 |
| Столбец с логином | `login = @l` | Login.cs | 18 |
| Столбец с паролем | `password = @p` | Login.cs | 18 |
| Текст роли администратора | `"Администратор"` | Form1.cs | 15 |
| Таблица пользователей (в списке) | `Items.Add("users")` | Form1.cs | 20 |
| Таблица товаров (в списке) | `Items.Add("products")` | Form1.cs | 22 |

### 8.1. У меня таблица пользователей называется по-другому

Например, в базе таблица `polzovateli` со столбцами `rol`, `log`, `parol`.
Меняем **только SQL-текст** в `Login.cs`:

```csharp
// было
"SELECT role FROM users WHERE login = @l AND password = @p"
// стало
"SELECT rol FROM polzovateli WHERE log = @l AND parol = @p"
```
`@l` и `@p` **не трогаем** — это параметры программы, а не столбцы.

### 8.2. ⚠️ Имена с большими буквами или по-русски — нужны двойные кавычки

PostgreSQL **сам переводит имена в маленькие буквы**. Если таблица в pgAdmin называется
`Users` (с большой) или `Пользователи` (по-русски, как часто бывает после импорта из Excel),
то без кавычек будет ошибка `relation "users" does not exist`.

В C# двойная кавычка внутри строки пишется как `\"`:

```csharp
// таблица "Пользователи", столбцы "Роль", "Логин", "Пароль"
"SELECT \"Роль\" FROM \"Пользователи\" WHERE \"Логин\" = @l AND \"Пароль\" = @p"
```

То же самое для списка таблиц в `Form1.cs`:
```csharp
comboBox1.Items.Add("\"Товары\"");
```

> 💡 Совет: проще **один раз переименовать** таблицы и столбцы в pgAdmin в маленькие латинские буквы
> (ПКМ по таблице → Properties → Name), тогда кавычки не нужны.

### 8.3. Хочу показывать ещё одну таблицу (например, заказы)

В `Form1.cs` добавить строку. Если таблицу должны видеть **все**:
```csharp
comboBox1.Items.Add("products");
comboBox1.Items.Add("orders");      // ← добавили
```
Если **только администратор** — внутрь `if (role == "Администратор") { ... }`.

Если **администратор и менеджер**:
```csharp
if (role == "Администратор" || role == "Менеджер")
    comboBox1.Items.Add("orders");
```
`||` значит «или».

### 8.4. Роль хранится не текстом, а номером (`role_id`) в отдельной таблице

Например: `users(id, role_id, login, password)` и `roles(id, name)`.
Тогда нужно **соединить** таблицы (`JOIN`), чтобы получить название роли:

```csharp
"SELECT r.name FROM users u JOIN roles r ON r.id = u.role_id WHERE u.login = @l AND u.password = @p"
```
- `users u`, `roles r` — короткие прозвища таблиц;
- `JOIN ... ON r.id = u.role_id` — «приклей к пользователю его роль по номеру»;
- `r.name` — берём название роли.

### 8.5. Хочу показывать ФИО, а не роль, в правом верхнем углу

По заданию в углу должно быть **ФИО**. Минимальная переделка:

1. В `Login.cs` запрос: `"SELECT role, full_name FROM users WHERE ..."`
2. Вместо `ExecuteScalar` читаем две колонки:
```csharp
var reader = cmd.ExecuteReader();
if (!reader.Read())
{
    MessageBox.Show("Неверный логин или пароль!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
    return;
}
string role = reader.GetString(0);
string fullName = reader.GetString(1);
reader.Close();
OpenMain(role, fullName);
```
3. `OpenMain(string role, string fullName)` и `new Form1(role, fullName)`;
4. В `Form1.cs`: `public Form1(string role, string fullName)` и `label1.Text = fullName;`
5. Гость: `OpenMain("Гость", "Гость");`

(В репозитории **ShoeShop-5** это уже сделано.)

### 8.6. Другая база данных целиком (другой вариант задания)

Чек-лист, ничего не забыть:
- [ ] `Database=` и `Password=` в **обоих** файлах;
- [ ] имя таблицы пользователей и трёх её столбцов в `Login.cs`;
- [ ] текст роли администратора в `Form1.cs` (как написано в базе);
- [ ] имена таблиц в `comboBox1.Items.Add(...)` в `Form1.cs`;
- [ ] у каждой таблицы, которую будут редактировать, есть **первичный ключ**;
- [ ] если имена русские или с большой буквы — кавычки `\"...\"`.

## 9. Частые ошибки и как их исправить

| Что видим | Почему | Что делать |
|---|---|---|
| `28P01: password authentication failed for user "postgres"` | неверный пароль в `connStr` | исправить `Password=` в обоих файлах |
| `3D000: database "shoes" does not exist` | нет такой базы | создать базу в pgAdmin или исправить `Database=` |
| `42P01: relation "users" does not exist` | нет такой таблицы (или она с большой буквы/по-русски) | проверить имя в pgAdmin; см. [8.2](#82-️-имена-с-большими-буквами-или-по-русски--нужны-двойные-кавычки) |
| `42703: column "role" does not exist` | нет такого столбца | проверить имена столбцов в pgAdmin (ПКМ по таблице → View/Edit Data) |
| `Failed to connect to 127.0.0.1:5432` | PostgreSQL не запущен | Пуск → «Службы» → postgresql → Запустить |
| При «Сохранить»: `Dynamic SQL generation ... not supported against a SelectCommand that does not return any key column information` | у таблицы нет первичного ключа | в pgAdmin добавить PRIMARY KEY (например, столбец `id serial primary key`) |
| При «Сохранить»: `23505: duplicate key` | добавили строку с уже существующим `id` | не заполнять `id` у новой строки — база поставит сама |
| `Npgsql` подчёркнут красным | не установлен пакет | NuGet → установить Npgsql |
| `CS7065 Формат потока значков отличается от ожидаемого` | `Icon.ico` из ресурсов — на самом деле PNG | убрать строку `<ApplicationIcon>` из `.csproj`; иконку окну ставить так: `Icon = Icon.FromHandle(new Bitmap("Icon.png").GetHicon());` |
| «Исполняемый файл ... не существует» | сборка не прошла | смотреть **Вид → Список ошибок**, там настоящая ошибка |
| Окно входа исчезло, а программа «висит» | забыли `Show()` после `ShowDialog()` | проверить метод `OpenMain` |
| `NullReferenceException` сразу при открытии окна | в конструкторе нет `InitializeComponent();` | добавить первой строкой в конструктор |

## 10. Как собрать это приложение с нуля на экзамене

1. **Visual Studio** → Создать проект → «Приложение Windows Forms» (C#) → .NET 8.
2. **NuGet:** ПКМ по проекту → «Управление пакетами NuGet» → Обзор → `Npgsql` → Установить.
3. **Окно входа:** ПКМ по проекту → Добавить → Форма (Windows Forms) → имя `Login`.
   Положить: 2 `TextBox`, 2 `Label`, 2 `Button`. У `textBox2` свойство `UseSystemPasswordChar = True`.
   Двойной щелчок по каждой кнопке. Вписать код из раздела 5.
4. **Главное окно** `Form1` (уже есть): положить `Label`, `ComboBox`, `DataGridView`, 2 `Button`.
   У `dataGridView1`: `ReadOnly = True`, `AllowUserToAddRows = False`, `AllowUserToDeleteRows = False`.
   Двойной щелчок по кнопкам; у `comboBox1` двойной щелчок по событию `SelectedIndexChanged`.
   Вписать код из раздела 6.
5. В `Program.cs`: `Application.Run(new Login());`
6. Поправить `connStr` в обоих файлах → **F5**.

**Порядок проверки перед сдачей:**
- вход под администратором → видны `users` и `products`, можно править и сохранить;
- вход под менеджером/клиентом → только `products`, править нельзя;
- «Войти как гость» → только `products`;
- неверный пароль → сообщение об ошибке, окно входа остаётся;
- «Выход» → возвращает на окно входа.
