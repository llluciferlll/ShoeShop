# Пошаговая инструкция: создаём приложение с нуля

От запуска Visual Studio до работающей программы. Базу данных в PostgreSQL считаем **уже созданной**.

**Что получится в конце:**
- окно входа: логин, пароль, «Войти», «Войти как гость»;
- главное окно: выбор таблицы, таблица с данными, «Сохранить» (только для администратора), «Выход».

---

## Шаг 0. Перед началом — узнать про свою базу

Откройте pgAdmin и запишите на листочек:

| Что | Где посмотреть | Пример |
|---|---|---|
| Имя базы | слева: Servers → PostgreSQL → **Databases** | `shoes` |
| Пароль PostgreSQL | тот, что вводите при входе в pgAdmin | `1234` |
| Таблица с пользователями | Databases → ваша база → Schemas → public → **Tables** | `users` |
| Столбцы логина, пароля, роли | раскрыть таблицу → **Columns** | `login`, `password`, `role` |
| Как записана роль администратора | ПКМ по таблице → View/Edit Data → All Rows | `Администратор` |
| Таблица с товарами | там же в Tables | `products` |

## Шаг 1. Создать проект

1. Запустить **Visual Studio 2022**.
2. В стартовом окне нажать **«Создание проекта»**.
3. В поиске сверху набрать `Windows Forms`.
4. Выбрать **«Приложение Windows Forms»** — с пометкой **C#**.
   > ⚠️ **Не** выбирать «Приложение Windows Forms (**.NET Framework**)» — это старая версия, будет по-другому.
5. Нажать **«Далее»**.
6. **Имя проекта:** `ShoeShop`.
   > Имя важно: оно станет `namespace` во всех файлах. Если назовёте иначе — ничего страшного,
   > просто в коде ниже везде, где написано `namespace ShoeShop`, оставляйте **своё** имя, которое
   > Visual Studio уже вписала в файл.
7. Расположение — любое, например `C:\Users\...\source\repos`. Нажать **«Далее»**.
8. **Платформа:** `.NET 8.0`. Нажать **«Создать»**.

Откроется пустое окно `Form1` в режиме дизайнера (серый квадрат).

> Если окно «Обозреватель решений» пропало: **Вид → Обозреватель решений** (Ctrl+Alt+L).

## Шаг 4. Нарисовать окно входа

### 4.1. Открыть панель элементов
**Вид → Панель элементов** (Ctrl+Alt+X). Слева появится список: Button, Label, TextBox...
Её удобно закрепить кнопкой-булавкой 📌 в заголовке панели.

### 4.2. Положить элементы
Перетащить мышкой на форму `Login`:

| Сколько | Что взять в «Панели элементов» | Куда поставить |
|---|---|---|
| 2 | **Label** | слева, одна под другой |
| 2 | **TextBox** | справа от надписей |
| 2 | **Button** | под полями ввода |

Visual Studio сама даст им имена: `label1`, `label2`, `textBox1`, `textBox2`, `button1`, `button2`.
**Эти имена не меняем** — код ниже написан под них.

### 4.3. Настроить свойства
Щёлкнуть по элементу → справа окно **«Свойства»** (если нет — клавиша **F4**) → найти свойство → вписать значение.

| Элемент | Свойство | Значение |
|---|---|---|
| `label1` | Text | `Логин:` |
| `label2` | Text | `Пароль:` |
| `textBox2` | UseSystemPasswordChar | `True` (пароль будет точками) |
| `button1` | Text | `Войти` |
| `button2` | Text | `Войти как гость` |
| сама форма (щёлкнуть по пустому месту формы) | Text | `Вход в систему` |
| сама форма | StartPosition | `CenterScreen` |
| сама форма | AcceptButton | `button1` (Enter = «Войти») |

> 💡 Чтобы быстро найти свойство — в окне «Свойства» есть строка поиска, или нажмите кнопку **«AZ»**
> (сортировка по алфавиту).

### 4.4. Создать обработчики кнопок
1. **Двойной щелчок** по кнопке `Войти` → откроется код, появится пустой метод `button1_Click`.
2. Вернуться в дизайнер: вкладка **`Login.cs [Конструктор]`** сверху.
3. **Двойной щелчок** по кнопке `Войти как гость` → появится `button2_Click`.

> ⚠️ **Не щёлкайте дважды по самой форме или по надписям** — создадутся лишние методы
> (`Login_Load`, `label1_Click`). Если случайно создали — **не удаляйте метод руками**,
> а: дизайнер → выделить элемент → в «Свойствах» вкладка ⚡ (События) → найти событие → стереть имя метода → Enter.
> Потом уже можно удалить пустой метод из кода.

## Шаг 5. Написать код окна входа

Открыть код: ПКМ по `Login.cs` в обозревателе → **«Просмотреть код»** (или F7).

**Стереть всё** и вставить (не забудьте поправить **строку подключения** под свою базу из шага 0):

```csharp
using Npgsql;

namespace ShoeShop
{
    public partial class Login : Form
    {
        string connStr = "Server=localhost;Port=5432;Database=shoes;User Id=postgres;Password=1234";

        public Login()
        {
            InitializeComponent();
        }

        private void button1_Click(object sender, EventArgs e)
        {
            using var conn = new NpgsqlConnection(connStr);
            conn.Open();
            var cmd = new NpgsqlCommand("SELECT role FROM users WHERE login = @l AND password = @p", conn);
            cmd.Parameters.AddWithValue("@l", textBox1.Text);
            cmd.Parameters.AddWithValue("@p", textBox2.Text);
            var role = cmd.ExecuteScalar();
            if (role == null)
            {
                MessageBox.Show("Неверный логин или пароль!", "Ошибка", MessageBoxButtons.OK, MessageBoxIcon.Error);
                return;
            }
            OpenMain(role.ToString());
        }

        private void button2_Click(object sender, EventArgs e)
        {
            OpenMain("Гость");
        }

        void OpenMain(string role)
        {
            Hide();
            new Form1(role).ShowDialog();
            textBox2.Clear();
            Show();
        }
    }
}
```

**Что подставить своё** (из шага 0):
- `Database=shoes` → имя вашей базы;
- `Password=1234` → ваш пароль PostgreSQL;
- `role`, `users`, `login`, `password` в SQL-запросе → ваши имена столбцов и таблицы.

> Сейчас `Form1(role)` будет подчёркнут красным — это нормально, исправим в шаге 7.

Сохранить: **Ctrl+S**.

## Шаг 6. Нарисовать главное окно (Form1)

1. В обозревателе **двойной щелчок** по `Form1.cs` → откроется дизайнер.
2. Растянуть форму пошире (потянуть за правый нижний угол), примерно в 2 раза.

### 6.1. Положить элементы

| Что взять | Куда поставить |
|---|---|
| **ComboBox** | сверху слева |
| **Label** | сверху справа |
| **DataGridView** (в разделе «Данные») | на всё свободное место посередине |
| **Button** | снизу слева |
| **Button** | снизу справа |

Имена получатся: `comboBox1`, `label1`, `dataGridView1`, `button1`, `button2`.

> Когда кладёте **DataGridView**, справа сверху у него появится маленькая стрелочка ▸ с окошком задач.
> Там **снять все галочки**: «Включить добавление», «Включить правку», «Включить удаление».
> (Это то же самое, что в свойствах ниже — можно сделать любым способом.)

### 6.2. Настроить свойства

| Элемент | Свойство | Значение |
|---|---|---|
| `comboBox1` | DropDownStyle | `DropDownList` |
| `label1` | Text | `Роль` |
| `label1` | Anchor | `Top, Right` (щёлкнуть по свойству → выбрать верх и право, остальное снять) |
| `dataGridView1` | **ReadOnly** | **`True`** |
| `dataGridView1` | **AllowUserToAddRows** | **`False`** |
| `dataGridView1` | **AllowUserToDeleteRows** | **`False`** |
| `dataGridView1` | Anchor | `Top, Bottom, Left, Right` (тянется вместе с окном) |
| `button1` | Text | `Выход` |
| `button1` | Anchor | `Bottom, Left` |
| `button2` | Text | `Сохранить` |
| `button2` | Anchor | `Bottom, Right` |
| сама форма | Text | `Работа с базой данных` |
| сама форма | StartPosition | `CenterScreen` |

> ⚠️ Три свойства `dataGridView1` выделены не зря: по умолчанию **все могут всё редактировать**.
> Мы запрещаем всем, а в коде разрешаем только администратору.

### 6.3. Создать обработчики
1. **Двойной щелчок** по кнопке `Выход` → `button1_Click`. Вернуться в конструктор.
2. **Двойной щелчок** по кнопке `Сохранить` → `button2_Click`. Вернуться в конструктор.
3. **Двойной щелчок** по `comboBox1` → появится `comboBox1_SelectedIndexChanged`.

## Шаг 7. Написать код главного окна

Открыть код `Form1.cs` (F7). **Стереть всё** и вставить:

```csharp
using System.Data;
using Npgsql;

namespace ShoeShop
{
    public partial class Form1 : Form
    {
        DataTable dt;
        string connStr = "Server=localhost;Port=5432;Database=shoes;User Id=postgres;Password=1234";

        public Form1(string role)
        {
            InitializeComponent();
            label1.Text = role;
            if (role == "Администратор")
            {
                dataGridView1.ReadOnly = false;
                dataGridView1.AllowUserToAddRows = true;
                dataGridView1.AllowUserToDeleteRows = true;
                comboBox1.Items.Add("users");
            }
            comboBox1.Items.Add("products");
        }

        private void comboBox1_SelectedIndexChanged(object sender, EventArgs e)
        {
            dt = new DataTable();
            new NpgsqlDataAdapter("select * from " + comboBox1.Text, connStr).Fill(dt);
            dataGridView1.DataSource = dt;
        }

        private void button2_Click(object sender, EventArgs e)
        {
            var da = new NpgsqlDataAdapter("select * from " + comboBox1.Text, connStr);
            new NpgsqlCommandBuilder(da);
            da.Update(dt);
            MessageBox.Show("Изменения сохранены", "Информация", MessageBoxButtons.OK, MessageBoxIcon.Information);
        }

        private void button1_Click(object sender, EventArgs e)
        {
            Close();
        }
    }
}
```

**Что подставить своё:**
- `connStr` — **точно такая же**, как в `Login.cs`;
- `"Администратор"` — как роль администратора записана в вашей базе;
- `"users"`, `"products"` — имена ваших таблиц.

Сохранить: **Ctrl+S**.

## Шаг 8. Сделать окно входа первым (Program.cs)

1. В обозревателе двойной щелчок по **`Program.cs`**.
2. Найти строку:
   ```csharp
   Application.Run(new Form1());
   ```
3. Заменить на:
   ```csharp
   Application.Run(new Login());
   ```
4. **Ctrl+S**.

Теперь все красные подчёркивания должны исчезнуть.
Проверить: **Вид → Список ошибок** — должно быть **0 ошибок**.

## Шаг 9. Запустить и проверить

Нажать **F5** (или зелёный треугольник ▶ ShoeShop сверху).

Проверить по списку (логины — из вашей таблицы пользователей):

| Действие | Что должно быть |
|---|---|
| Ввести неверный пароль → «Войти» | красное окно «Неверный логин или пароль!», окно входа остаётся |
| Войти **администратором** | справа сверху «Администратор»; в списке `users` и `products` |
| Выбрать `products` | таблица заполнилась |
| Изменить ячейку → «Сохранить» | «Изменения сохранены»; в pgAdmin значение тоже поменялось |
| «Выход» | снова окно входа, пароль стёрт |
| Войти **менеджером** или **клиентом** | в списке только `products`, ячейки не редактируются |
| «Войти как гость» | справа «Гость», только `products` |

Закрыть программу — крестик на окне входа.

> Если что-то пошло не так — таблица ошибок в [ОПИСАНИЕ_КОДА.md, раздел 9](ОПИСАНИЕ_КОДА.md#9-частые-ошибки-и-как-их-исправить).
